## 目录

- `01_supplement_audit/`：125篇页面与补充材料审查。
- `02_evidence_chain_change_log.csv`：证据链、DOI和情境修订日志。
- `03_revised_results/`：论文、案例、证据链、工具、RQ2审查主数据。
- `04_RQ1/`：总体、年代、领域和阶段分布。
- `05_RQ2/`：7项规范性分布、质量层级和状态变化。
- `06_RQ3/`：模型、两种贡献检验、稳健权重和one-SE阈值。
- `07_robustness_comparison/`：修订前后分布、权重、模型和标签比较。
- `08_QC/`：外键、唯一性、代码合法性、7项覆盖等质量检查。
- `reports/`：可直接审阅的研究报告。
- `08_网页推荐器更新建议.md`：基于新版双重稳健检验与one-SE阈值提出的网页更新方案；未自动覆盖现有网站。
- `deliverables/`：三份Excel交付表。

## 重要限制

官方页面受限的补充附件未被推定内容；只有可追溯到正文、整合附录或明确官方记录的信息才改变编码和RQ2判定。未映射项继续保留，避免为了提高覆盖率而扩大既定二级分类。
