# 补充材料增强后的 RQ1–RQ3 重分析实施方案（待审查）

## 1. 文档目的

本文档用于在不覆盖现有结果的前提下，规定补充材料纳入后的数据修订、RQ1 重算、RQ2 重审、RQ3 重新建模和修订前后稳健性比较流程。本文档是待审查的实施规程，不代表已经修改当前数据或研究结论。

## 2. 本轮重分析需要回答的核心问题

1. 在补充材料、在线问卷、数据附录和作者公开仓库纳入后，评价维度、主观指标和测量工具的分布是否发生实质变化？
2. 补充材料是否提供了正文 PDF 中缺失的题项、计分、信效度、抽样、实施、分析或可追溯性信息，从而改变 RQ2 的规范性判定？
3. 补充材料增强后的主要规范集和扩展规范集是否改变 RQ3 中 G1–G7 与评价维度、主观指标、测量工具之间的关系？
4. 修订前后的分布、规范性结论、模型表现、标签权重和推荐标签集是否稳健？

## 4. 补充材料的完整审查范围

### 4.1 全覆盖原则

不对论文或补充材料设定高、中、低审查优先级。对 125 篇论文的在线发表页逐篇检查；对所有可获取的补充文件、在线问卷、数据附录、作者资料库和论文内置附录使用完全相同的审查深度和编码规则。

已初步确认有独立补充材料或正文明确指向补充文件的论文包括 11、18、21、22、37、45、58、75、102、103、117、120、121、122；论文 85 的研究任务和质性编码本已并入 PDF 附录。这些只是当前已确认的条目，不构成封闭名单；对其余论文仍需核对发表页上是否存在未被 PDF 链接提取识别的附件。

论文 122 在现有数据中的 DOI 是占位符，应更正为 `10.1145/3528223.3530056`，再重新匹配其发表页和补充材料。

### 4.2 每份补充材料的统一审查顺序

对每份补充材料都依次完成以下工作，不根据预判的“相关性”缩减任何步骤：

1. **RQ1 新案例检查**：是否揭示独立的参与者批次、评价任务、实验条件或评价实施；
2. **RQ1 新证据链检查**：是否包含正文未编码的效果主张、感知构念、主观指标或结果；
3. **RQ1 原链修订检查**：是否能恢复未映射评价维度／主观指标，或纠正现有映射；
4. **RQ1 工具实例检查**：是否揭示额外的量表、自编评分、访谈、问卷或既有感知资料分析；
5. **RQ2 规范性证据检查**：是否补充题项、计分、信效度、参与者、招募、任务、程序、分析、结果和可追溯性信息。

上述第 1–4 步完成后，先将所有新增和修订记录纳入 RQ1 并重新计算 RQ1；然后再在第二阶段使用第 5 步的信息更新 RQ2。

### 4.3 补充材料的证据来源与可追溯性顺序

只采用可追溯到正式发表页或作者／机构官方仓库的材料，优先级依次为：

1. 出版商正式补充文件；
2. 论文发表页直接链接的数据集、问卷或附录；
3. 作者所在机构的正式仓库；
4. 论文明确声明的作者 GitHub／Zenodo 仓库。

不将论文引用的第三方软件仓库、基础模型仓库或普通网页误判为论文补充材料。无法获取的附件标记为 `SUPPLEMENT_UNAVAILABLE`，不根据标题或文件名推测其内容。

## 5. 第一阶段（A）：纳入补充材料并修订／新建 RQ1 证据链

第一阶段的直接目标是产生补充材料增强后的 RQ1 完整数据并重新计算 RQ1，而不是只做一份中间编码表。本阶段内部按“获取补充材料 → 修订原证据链／新建证据链 → 重算 RQ1”的顺序连续完成。RQ2 的规范性层级不作为 RQ1 的纳入门槛。

### 5.1 审查单位

继续使用“一条证据链=一次评价实践”的口径，但每条证据链同时连接：

- 论文级信息：发表时间、来源、设计领域等；
- 案例级信息：设计任务、设计阶段、AI 功能、参与者和评价情境；
- 证据链级信息：效果主张 → 评价维度 → 主观指标 → 测量工具／方法 → 结果。

### 5.2 新增数据源字段

为了区分正文与补充材料证据，新增以下字段：

| 字段 | 含义 |
|---|---|
| `source_layer` | `MAIN_PDF` / `SUPPLEMENT` / `ONLINE_INSTRUMENT` / `OFFICIAL_REPOSITORY` |
| `source_url_or_file` | 可追溯文件或链接 |
| `source_location` | 页码、附录、表格、题号或文件名 |
| `supplement_availability` | `AVAILABLE` / `UNAVAILABLE` / `NOT_FOUND` / `INTEGRATED_IN_PDF` |
| `mapping_change` | `UNCHANGED` / `RECOVERED` / `RECODED` / `NEW_CHAIN` / `STILL_UNMAPPED` |
| `change_reason` | `REPORTING_GAP` / `EXTRACTION_MISS` / `SUPPLEMENT_RECOVERY` / `TAXONOMY_GAP` / `NOT_PERCEIVED_EFFECT` |
| `baseline_chain_id` | 与修订前证据链对应；新建链留空 |

### 5.3 未映射记录的处理规则

1. 对 58 条评价维度未映射记录和 6 条主观指标未映射记录逐条回到正文、图表和补充材料复核。
2. 不将“未映射”直接等同于“不规范”。
3. 如果论文已提供清晰构念／指标，但原编码漏提取，标记为 `EXTRACTION_MISS`。
4. 如果信息只在补充材料中出现，标记为 `SUPPLEMENT_RECOVERY`。
5. 如果论文只笼统报告“问卷／评分／访谈”，无法确定具体构念或指标，标记为 `REPORTING_GAP`。
6. 如果构念和指标清晰，但不在现有分类中，标记为 `TAXONOMY_GAP`。
7. 如果复核后发现该记录不是人类主观感知评价，标记为 `NOT_PERCEIVED_EFFECT`，从 RQ1 和 RQ3 主分析中排除，但保留审查轨迹。

### 5.4 分类体系的变更规则

- A–E 五类评价维度、36 个既定主观指标和 M1–M5 测量工具分类作为核心体系，不为了消除 UNMAPPED 而强行归类。
- 复合指标只在论文将各组成部分独立操作化时才拆分；否则保留为 `COMPOSITE_UNMAPPED`。
- 新增二级指标必须同时满足：概念边界与现有指标明显不同，有可追溯题项／定义，并且有理论依据或至少 3 篇独立论文支持。
- 如需新增分类，先输出“分类变更建议表”，不在未审查的情况下直接改变核心分类。

### 5.5 去重和新建证据链规则

- 同一效果主张使用多个工具：保留一条证据链，但生成多个测量工具实例。
- 同一问卷测量多个不同构念：按构念拆分为多条证据链。
- 正文与补充材料报告同一条链：只增加证据来源，不重复建链。
- 补充材料报告正文未出现的独立构念和结果：新建证据链，并标记 `NEW_CHAIN`。

### 5.6 补充材料中新证据链的纳入规则

补充材料不仅用于补足现有证据链的题项、计分、信效度或实施信息，也可能揭示正文未被识别的新评价构念、新效果主张或新评价实施。这些内容必须新建证据链并纳入 RQ1，不得只作为 RQ2 的附加审查证据。

#### 5.6.1 何时新建证据链

补充材料中出现以下任一情况时，新建一条证据链：

1. 出现正文未报告的独立 Perceived effect 效果主张；
2. 同一评价问卷或访谈工具中出现正文未识别的独立感知构念；
3. 补充数据报告了某构念的独立指标、结果和解释，能够形成完整的“效果主张—评价维度—主观指标—测量工具”对应；
4. 补充材料揭示了与正文不同的评价主体、评价对象、设计情境或实验条件，且独立产生了一组评价结果；
5. 正文只笼统说明“进行了问卷／访谈／专家评分”，而补充材料使其中的多个独立构念可被分别识别。

仅增加同一构念的题项原文、计分细节、参与者说明、附加分析或可追溯位置时，不新建证据链，而是增强已有证据链。

#### 5.6.2 新证据链与评价案例的关系

- 新构念来自已识别的同一批参与者、同一任务和同一实施程序：使用原有 `eval_id`，新建 `chain_id`。
- 补充材料揭示了独立的参与者批次、任务、实验条件或实施阶段：先新建 `eval_id`，再在新案例下建立证据链。
- 只有额外测量工具、但仍测量同一效果主张和构念：不新建证据链，只新增测量工具实例。

#### 5.6.3 新证据链进入各研究问题的规则

| 研究问题 | 纳入规则 |
|---|---|
| RQ1 | 只要符合 Perceived effect 范围并有可追溯依据，新证据链就进入 RQ1；不以 RQ2 是否达到规范性门槛为前提 |
| RQ2 | 对所有新证据链按相同七项标准审查，不因其来自补充材料而预设为规范 |
| RQ3 | 只有完成必要映射、并达到主要规范集或扩展规范集纳入条件的新证据链才进入相应模型 |

#### 5.6.4 RQ1 对新证据链的专门报告

RQ1 除了重新计算修订后的总体分布，还需单独报告：

- 补充材料新增的评价案例数、证据链数和测量工具实例数；
- 新证据链分别来自哪些论文和补充材料；
- 新证据链在评价维度、主观指标、测量工具、设计领域和设计阶段上的分布；
- 修订后 RQ1 的数量变化中，有多少来自新证据链，有多少来自对原证据链的重新映射；
- 将新证据链纳入前后的 RQ1 分布差异，作为单独的增量敏感性分析。

## 6. 第一阶段（B）：用补充材料增强后的完整数据重新计算 RQ1

本节与第 5 节同属第一阶段。只有当补充材料中的新证据链、恢复映射的原证据链和新增测量工具实例全部纳入后，才开始生成 RQ1 的总体分布、年代趋势和情境交叉结果。第一阶段的交付条件是完成 RQ1 修订结果报告，而不是仅完成数据编码。

### 6.1 分析数据集

RQ1 的修订后总数据集包括：原 490 条候选证据记录经复核后的保留记录、从原未映射记录中恢复的完整证据链，以及补充材料中新识别的证据链。RQ1 是对现存评价实践的描述性梳理，因此新证据链是否进入 RQ1 由内容是否属于 Perceived effect 评价决定，而不由 RQ2 规范性等级决定。

RQ1 同时报告三个口径：

1. **全部候选记录数**：包括仍未映射记录，用于透明报告数据完整度；
2. **已映射评价维度记录数**：用于 A–E 分布；
3. **完整证据链数**：用于二级主观指标分布及其情境交叉分析。

测量工具分析以“工具实例”为单位，不以证据链数为分母；一条证据链使用多个工具时会贡献多个工具实例。

### 6.2 需重新生成的 RQ1 结果

1. 评价维度 A–E 的总体分布和年代趋势；
2. A–E 五个维度内各二级主观指标的总体分布和年代趋势；
3. M1–M5 测量工具的总体分布和年代趋势；
4. 评价维度×设计领域、评价维度×设计阶段；
5. 主观指标×设计领域、主观指标×设计阶段；
6. 测量工具×设计领域、测量工具×设计阶段；
7. 修订前后未映射比例及未映射原因分布。
8. 补充材料新增证据链的单独分布，及其对总体分布的增量贡献。

### 6.3 统计规则

- 总体分布同时报告原始计数、有效分母和构成比。
- 多标签的设计领域或设计阶段在交叉表中采用展开计数，因此构成比只在各情境内解释，不将展开后总数当作独立证据链数。
- 稀疏交叉表主要作描述性解释；若进行独立性检验，同时报告低期望频数比例和 Cramér’s V，必要时使用蒙特卡罗精确检验，不仅报告 p 值。
- 年代趋势同时报告“年度原始数量”和“当年证据构成比”，避免将年度论文总量增长误解为某类评价偏好增长。

### 6.4 RQ1 输出

- `RQ1_revised_counts_and_percentages.csv`
- `RQ1_revised_cross_tabs.xlsx`
- `RQ1_revised_figure_tables.xlsx`
- `RQ1_revised_results_report.md`
- 所有图形的可重绘数据表
- `RQ1_baseline_vs_revised.csv`

## 7. 第二阶段：更新 RQ2 规范性判定

### 7.1 审查体系保持不变

使用现有七项核心标准 U5、A2、A3、A4、A6、A7、E1 及其 41 条可观察子规则。本轮只补充证据来源和更新判定，不同时修改标准定义，以保证修订前后可比。

### 7.2 判定原则

1. 每条证据链结合论文级、案例级和证据链级信息审查。
2. 补充材料与正文具有同等的报告证据作用，但必须保留来源和位置。
3. 不因为“存在补充材料”而整体提高等级；只更新其实际支持的子规则。
4. 不将“未报告”自动解释为“方法未实施”；RQ2 判断的是基于可获取文献的报告充分性与方法适切性。
5. 不将 UNMAPPED 直接判为 C；需根据七项标准分别判定。
6. 新建证据链使用与旧链完全相同的规则审查。

### 7.3 审查流程

1. **第一遍：数据提取。** 仅记录原文证据，不立即修改质量层级。
2. **第二遍：子规则审查。** 对 41 条子规则重新判定 S／P／C／NA，并保留原文与补充材料的证据位置。
3. **质量层级重算。** 按现有 Q1／Q2／Q3／EXCLUDE 操作化规则重新计算，不为了扩大建模样本而降低门槛。
4. **变更核查。** 对所有层级变化的证据链生成“修订前判定—新证据—修订后判定—变更理由”对照表。

### 7.4 RQ2 必须报告的新结果

- 490 条原候选记录及所有新建证据链的最终审查数；
- 补充材料使哪些子规则从 C 或 P 变为 P 或 S；
- U5、A2、A3、A4、A6、A7、E1 的 S／P／C／NA 分布；
- 41 条子规则的满足率和最常见缺口；
- Q1／Q2／Q3／EXCLUDE 的修订前后转移矩阵；
- 主要规范集和扩展规范集的新样本数。

### 7.5 RQ2 输出

- `RQ2_revised_subrule_audit.csv`
- `RQ2_revised_chain_quality.csv`
- `RQ2_quality_transition_matrix.csv`
- `RQ2_supplement_evidence_log.csv`
- `RQ2_revised_results_report.md`

## 8. 第三阶段：重新训练 RQ3

### 8.1 输入数据集

- **主要规范集**：按更新后 Q1／Q2 规则构建；
- **扩展规范集**：按更新后扩展纳入规则构建；
- 两个数据集都必须记录论文 ID，用于论文分组的训练／测试划分。

### 8.2 情境标签 G1–G7

| 组 | 内容 |
|---|---|
| G1 | 评价目的：价值引出与标准建构；模型监督、校准与代理目标；形成性反馈与迭代引导；总结性验证与比较 |
| G2 | 设计领域：视觉传播、工业／产品、时装、室内、服务、UI/UX |
| G3 | 设计阶段：研究、构思、原型制作与测试、实施 |
| G4 | 评价对象：设计成果或解决方案；设计任务或工作流程；AI 辅助设计系统或界面；人的状态或能力；人机协作关系 |
| G5 | 评价主体：设计任务执行者；设计成果使用者；外部领域专家；一般公众／非目标人群；内部研究者／系统开发者 |
| G6 | 目标用户：专业设计从业者；设计学习者／新手设计者；非专业创作者 |
| G7 | AI 功能：识别需求、知识检索、方案生成、原型实现、评估反馈、迭代优化 |

### 8.3 三层预测目标

1. **评价维度层**：预测 A–E 评价维度；
2. **主观指标层**：在已知评价维度的条件下，预测该维度内的二级指标；
3. **测量工具层**：在已知评价维度和主观指标的条件下，预测 M1–M5 工具类别。

主观指标层不纳入指标未映射记录；测量工具层以工具实例为观测单位。

### 8.4 模型和验证设计

为保证修订前后可比，保持与现有 RQ3 相同的模型族和评价逻辑：

- 频率／多数类基线；
- L2 多项逻辑回归；
- 随机森林；
- 直方图梯度提升。

具体规则：

1. 使用论文分组交叉验证，避免同一论文的多条证据链同时出现在训练集和测试集。
2. 保持原有输出类别的最小支持门槛：至少 5 个观测且来至至少 3 篇独立论文。
3. 每层以 Macro-F1 选择表现最佳的非基线模型，同时报告 Top-2 准确率、平衡准确率和混淆矩阵。
4. 保持现有随机种子、折数和参数设定，主要比较数据修订本身带来的变化。
5. 如新数据使某些类别首次达到最小支持门槛，单独报告其对模型类别数和难度的影响。

### 8.5 标签权重和稳健性检验

对每一层的最佳模型重新执行：

1. **逐组消融检验**：每次移除 G1–G7 中一个标签组，比较 Macro-F1 变化；
2. **测试集置换检验**：只扰乱某一标签组，检查其对未见论文预测的贡献；
3. **折间稳定性**：报告正向贡献折比例、权重均值和置信区间；
4. **综合排序权重**：只对同时达到稳健性和层级最佳阈值的标签进入默认推荐流程。

### 8.6 与现有网页推荐器的衔接

重新建模先计算 G1–G7 的完整关系，但在网页默认渐进式披露中，先检验现有稳健标签集是否仍成立：

- 评价维度层：只使用 G4 评价对象；
- 主观指标层：只使用 G1 评价目的和 G2 设计领域；
- 测量工具层：只使用 G3 设计阶段、G7 AI 功能、G1 评价目的和 G6 目标用户。

如修订后数据不再支持上述标签集，先在稳健性报告中呈现差异，不自动改动网页。

## 9. 第四阶段：比较修订前后结果并判断稳健性

### 9.1 比较原则

- 修订前后采用相同的分类口径、模型族、分组交叉验证和评价指标。
- 如果分类体系确实必须变更，同时输出“旧分类口径的可比结果”和“新分类口径的完整结果”，不把分类体系变化误当作研究现象变化。
- 统计比较以论文为重抽样单位，使用论文级配对 bootstrap 置信区间，避免将同一论文的多条证据链当作完全独立样本。

### 9.2 RQ1 稳健性比较

| 比较项 | 指标 |
|---|---|
| 样本完整度 | 候选记录、已映射维度、完整证据链、工具实例的数量变化 |
| 构成比变化 | 每个主要类别修订前后的百分点差 |
| 分布整体差异 | Jensen–Shannon divergence，辅以总变差距离 |
| 排名稳定性 | Spearman 排名相关 |
| 核心结论 | 前 3 个主要类别、主要年代趋势和领域／阶段特征是否一致 |

### 9.3 RQ2 稳健性比较

- 七项标准和 41 条子规则的 S／P／C／NA 构成变化；
- Q1／Q2／Q3／EXCLUDE 证据链数量变化；
- 主要规范集和扩展规范集的扩大比例；
- 最常见的五个规范性缺口排名是否改变；
- 哪些变化是补充材料带来，哪些是原编码漏提取带来。

### 9.4 RQ3 稳健性比较

| 比较项 | 指标 |
|---|---|
| 最佳模型 | 每层最佳模型类型是否改变 |
| 模型表现 | Macro-F1、Top-2 准确率、平衡准确率的配对折差值及 95% 置信区间 |
| 权重变化 | 各 G 组权重的百分点差和排名相关 |
| 稳健标签 | 正向贡献折比例、置换贡献和阈值纳入状态 |
| 推荐标签集 | 修订前后入选标签的 Jaccard 相似度 |
| 推荐结果 | 对固定测试情境生成 Top-k 推荐，比较排名一致性 |

### 9.5 预先规定的稳健性判定标准

下列标准为本研究的操作化判定规则，不是通用行业标准。以置信区间和结论方向为主，数值阈值为辅。

#### RQ1 可判定为稳健，需同时满足

- A–E 及 M1–M5 的前 3 个主要类别不变；
- 主要类别构成比的最大绝对变化不超过 5 个百分点；
- 类别排名 Spearman ρ ≥ 0.80；
- 年代趋势的主要方向不改变。

#### RQ2 可判定为稳健，需同时满足

- 七项标准的主要满足顺序不变；
- 单项标准 S 或 S+P 比例的变化不超过 5 个百分点，或配对 bootstrap 置信区间显示差异很小；
- 主要规范性缺口的前 5 项中至少 4 项保持一致。

#### RQ3 可判定为稳健，需同时满足

- 每层最佳模型的 Macro-F1 变化绝对值不超过 0.05，或配对差值的 95% 置信区间包含 0；
- 标签权重排名 Spearman ρ ≥ 0.80；
- 单个入选标签的权重变化不超过 10 个百分点；
- 阈值入选标签集的 Jaccard 相似度 ≥ 0.80；
- 维度层 G4、指标层 G1+G2、工具层 G3+G7+G1+G6 的默认披露逻辑未被新数据明显否定。

只有当 RQ1、RQ2 和 RQ3 的核心结论均通过相应稳健性判定，才在论文中表述为“主要结论对补充材料增强和编码修订具有稳健性”。

### 9.6 结果不稳健时的处理

如任一核心结论不稳健：

1. 不选择性保留旧结果；
2. 定位变化来源：新建证据链、补充材料恢复、原编码漏提取、分类变更或质量层级转移；
3. 分别做“只加补充材料”和“补充材料+编码纠错”两个敏感性版本；
4. 将新结果作为主结果，旧结果仅作为方法迭代记录；
5. 在网页推荐器更新前，单独提交标签选择逻辑变更报告。
